Rockbar for EDCB
==============
Rockbar for EDCBはEDCBと連携し、番組・予約情報の表示や視聴(TVTest連携)を行うアプリケーションです。

## コンセプト
TVRockのRockバー相当の見た目・機能をEDCBで使うことを目的としています。

EDCBは録画に関しては非常に高い機能性を持ちますが、気軽にザッピングしたり録画と視聴を柔軟に組み合わせるのがやや不得意なため、視聴面を補完する目的で作成しました。

EDCBでは録画だけを管理し、本アプリケーションで視聴面を補完する使用方法を想定しています。

## 動作環境
- Windows10 64bit
- .NET Framework 4.8以上

※バイナリは64bit版のみ配布とします。TVTestやEDCBと32bit/64bitを揃える必要はありません。

## 制限事項
TVTestでの視聴はSpinel, BonDriverProxyEx, VirtualPTなどチューナー共有の仕組みを導入していることを前提としています。

チューナー共有なしだとTVTest連携周りは使いものにならないか、録画失敗を頻発させる可能性がありますのでくれぐれもご注意ください。

本アプリケーションの使用で発生したいかなる損害についても、作者は一切責任を負いません。

## 機能
- **チャンネル(全て,地デジ,BS,CS,お気に入り)タブで現在放送中の番組・予約ステータスを表示**
  - チャンネル欄右クリックで直近30件の番組一覧を表示（コンテキストメニュー。TVRockを踏襲）
    - サブメニューに番組詳細を表示（クリップボードにコピー可能）
    - サブメニュー1行目にWeb番組詳細へのリンクを表示可能（デフォルトブラウザで開きます）
    - サブメニューで予約の追加・有効化/無効化・削除が可能
  - チャンネル欄中央クリックで予約の追加・有効化/無効化を実行
  - チャンネル欄ダブルクリックでTVTestを起動
  - 絞り込みフィルタ: フィルタ文字列入力で現在放送中の番組を絞り込み（ResetボタンまたはEscキーで解除）
    - 利用想定：どこかのチャンネルでスポーツ番組をやっているが分からない場合など
    - スペース区切りでAND検索
    - `-`（ハイフン）で始まる文字列でNOT検索
  - 各タブの表示対象:
    - 全て：全チャンネル
    - 地デジタブ：地デジ
    - BSタブ：BS、BS4K
    - CSタブ：CS、CATV、SPHD※現スカパー!プレミアムサービス
    - お気に入りタブ：お気に入り設定されたチャンネル
- **新番組タブで新番組タグが付いている番組一覧を表示**
  - 基本操作はチャンネルタブと同じ（ダブルクリック時はWeb番組詳細をデフォルトブラウザで開きます）
- **予約タブで予約済みの番組・予約ステータス・使用予定チューナーを表示**
  - 基本操作はチャンネルタブと同じ（ダブルクリック時はWeb番組詳細をデフォルトブラウザで開きます）
- **録画タブで録画済みの番組・録画ステータスを表示**
  - 基本操作はチャンネルタブと同じ（中央クリックは動作しません）
- **チューナー一覧で直近の予約と現在実行中の予約情報を表示**
  - チューナー欄右クリックで直近30件の予約一覧を表示
  - 一部録画・チューナー不足の予約が入っているチューナーは背景色を変えて可視化（直近30件に限らず警告）
- **表示設定の柔軟性**
  - EDCBで定義されているチャンネル情報を取得し、表示するチャンネルの選択・並び順の設定が可能
  - 手動でチャンネル情報を編集することが可能
  - 一部録画・チューナー不足になりそうな予約は背景色やマークを変えて可視化
- **TVTest連携の自動化**
  - 予約開始タイミングで自動的にTVTestを起動し、終了時に自動で閉じる機能
  - 同一チャンネルで連続した番組はTVTestの自動追加起動を抑制（ダブルクリック起動のTVTestは対象外）
  - 自動起動対象は地デジ・BS・CS・お気に入りサービスなどでフィルタ可能
  - 自動起動・終了タイミングは59秒以内で調整可能
- **UI・デザインカスタマイズ**
  - タスクトレイへの格納・アイコン表示（クリック時の動作切替可能）
  - 終了時のウィンドウサイズ・起動位置・スプリッタ位置を自動記憶
    - デフォルトに戻したい場合は、設定ファイルの `Width`, `Height` を削除して起動してください
  - メイン画面のListView内・コンテキストメニューのフォント設定
  - メイン画面の枠・ListView背景色・文字色・コンテキストメニュー背景色のカスタマイズ
  - BonDriver名に対するチューナー名の内部設定
  - etc...

インストーラは付属しません。

Releasesから `RockbarForEDCB-********.zip` をダウンロードし、任意のディレクトリを作成して展開してください。<br>

## アップグレード
Releasesから最新の `RockbarForEDCB-********.zip` をダウンロードし、exeファイルを上書きしてください。<br>
※不具合等で設定ファイルの内容が消去されるリスクに備え、事前に設定ファイルのバックアップを取得しておくことを推奨します。

## 使い方
`RockbarForEDCB.exe` を起動してください。

## 設定
「設」ボタン、またはタスクトレイアイコンの右クリックメニューから設定画面を開き、設定を行います。<br>
まずはEDCB連携設定を行い、EpgTimerSrvと通信できる状態にしてください。

### EDCB連携設定
デフォルトはローカルパイプ通信になっており、EpgTimerSrvと同じPCで実行する場合は起動時点で通信ができるはずです。通信ができない場合は起動時に警告が出ます。

* **TCP/IP通信の設定:**
  * 「EDCBとの通信にTCP/IPを使用する」をチェック
  * EpgTimerSrv側で設定したポート番号に合わせる（EDCB上のEpgTimerSrv設定 → その他 → ネットワーク接続を許可する配下）
* **番組表リンクの設定:**
  * 「Web番組表機能(WebUI)を使用する」をチェック
  * 「番組表URL」、「Web番組詳細URL」、「録画詳細URL」を設定（EMWUIをローカルで使用する場合はデフォルトのままで使用可能）
  * 例（EMWUI用）: `http://localhost:5510/EMWUI/epginfo.html?onid={ONID}&tsid={TSID}&sid={SID}&eid={EID}`
  * 例（legacy用）: `http://localhost:5510/legacy/epginfo.html?{ONID}-{TSID}-{SID}-{EID}`

### 予約設定
Rockbar for EDCBから予約の追加、変更、削除をする場合に設定します。<br>
※未設定かつEDCB連携設定で「Web番組表機能(WebUI)を使用する」が有効な場合、番組を中央クリックするとWebブラウザで番組詳細が開きます。

* **予約追加**
  * 有効時、予約が入っていない番組への中央クリックや右クリックメニューから予約追加が可能になります。
  * EpgTimerSrvを介してEDCB予約プリセットを取得できないため、追加内容の事前設定が必要です。
  * 優先モード（「視聴」または「録画」）は、中央クリックで予約追加した際に適用されます。
* **予約変更**
  * 有効時、予約が入っている番組に対して中央クリックや右クリックメニューから有効/無効の切り替えが可能になります。
* **予約・録画情報削除**
  * 有効時、予約が入っている番組や録画済み番組に対して右クリックメニューから削除が可能になります。
  * 削除時の確認ダイアログが不要な場合は「削除前確認表示」のチェックを外してください。

### チューナー名設定
BonDriver名に対してRockbar for EDCB上の表示名を設定できます。BonDriver名から自動で割り当てられますが、意図しない名称になっている場合は適宜調整してください。

### チャンネル設定
メイン画面に表示するチャンネルを設定します。

#### 選択チャンネル
- **全チャンネル:** EDCBから取得したチャンネル一覧（通信できていない場合は空になります）。
- **選択チャンネル:** 「全チャンネル」から選択して保存すると、本体の「全て」タブに反映されます（並び順も保持）。
- **種類列:** 「地」「BS」「CS」「CATV」「SPHD」「BS4K」に基づき、表示タブやTVTest起動時のBonDriver選択等に使用されます。
- **手動追加:** EPGが取得できていないチャンネルも、TSIDとSIDを手動指定して追加可能です。
- **手動編集:** 放送の種類やチャンネル名は手動変更可能。チャンネル毎に個別でTVTestオプションも指定できます（CATV契約のチャンネルを専用チューナーで開く場合などを想定）。
- **ステータス表示:** 「全チャンネル」に存在しないチャンネルは `A` (Add)、「全チャンネル」から情報変更されたものは `M` (Mod) と表示されます。

#### お気に入りチャンネル
- 「選択チャンネル」は「選択チャンネル」タブで選んだチャンネルです。
- 「選択チャンネル」から選択して保存することで、本体の「お気に入り」タブにチャンネルが表示されます（並び順も保持）。

### TVTest連携設定
TVTest連携を行う場合、`TVTest.exe` のパスを指定し、地デジやTS再生などの起動オプションを設定してください。

オプションにはBonDriverの指定（`/d BON_DRIVER`）や複数起動制限（`/s`）などを設定します。

* **設定例（地デジ）:**
  `/s /d BonDriver_PT3_T.dll`
* **設定例（TS再生）:**
  `/d BonDriver_Pipe.dll`

※TVTest起動時には上記オプションに加え、`/TSID` および `/SID` オプションが自動で付与されます。<br>
※特定のチャンネルに個別オプションが必要な場合は「選択チャンネル」タブから設定してください。

### 設定ファイル
- **選択チャンネル一覧:** `SelectedServices.tsv`
- **お気に入りチャンネル一覧:** `FavoriteServices.tsv`
- **その他の設定:** `RockbarForEDCB.toml`

## やってること・仕様
- 1分間隔(毎分00秒)でEPGTimerSrvと通信して、最新の番組一覧・予約一覧を取得して表示更新します。
  - EDCB側の変更をリアルタイムに取得したりはしないので、必ず00秒を待つ必要があります。
- 通信ボリュームが結構あります。内部的に番組一覧をメモリにキープするのでメモリも結構食います。
  - テスト範囲ではローカルパイプ＋地上波アニメ全録くらいの運用であれば大した負荷にならなさそうですが、重いシチュエーションがあれば報告してください。
  - 特にTCP/IPでホストが離れてるケースとかは全くテストしてません。
- 実装にはEDCB内のCtrlCmd.cs, CtrlCmdDef.cs, DefineEnum.csを組み込んで利用しています。
